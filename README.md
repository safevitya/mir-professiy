# Мир профессий

Образовательное веб-приложение (набор из 5 мини-игр для знакомства с профессиями: Комплектовщик, Оператор, Специалист по этикеткам, Садовник, Сборщик изделий).

## Требования

Для запуска проекта должен быть установлен **[Node.js](https://nodejs.org/)** (версии 18 или выше).

## Как запустить проект

1. **Скачай проект** (или клонируй репозиторий) и открой терминал в папке проекта.

2. **Установи зависимости** (библиотеки):
   ```bash
   npm install
   ```

3. **Запусти сервер для разработки**:
   ```bash
   npm run dev
   ```

4. **Открой в браузере** ссылку, которая появится в терминале (обычно это `http://localhost:5173`).

> 💡 **Совет по озвучке:** Для самого качественного и живого голоса озвучки рекомендуется открывать проект в браузере **Microsoft Edge** или **Google Chrome** (выбрать голос можно внутри игры в меню **«Настройки»**).

## Дополнительные команды

- `npm run check` — запуск автопроверки генератора заданий и игровой логики.
- `npm run build` — сборка готовой версии проекта в папку `dist`.
- `npm run preview` — локальный просмотр собранной версии.

> ⚠️ **Для пользователей Windows (PowerShell):** Если при вводе `npm ...` возникает ошибка `running scripts is disabled on this system`, используй `npm.cmd` вместо `npm` (например: `npm.cmd install` и `npm.cmd run dev`) или запускай команды через обычную командную строку (`cmd`).
